# The World in One Day — 33 Stories, 20 November 2026

A square 1:1 editorial news infographic poster in a **world-atlas** style:
a deep-teal header carries a strip map of the world with graticule lines,
continent labels, amber coordinate dots and three numbered pins for the
hero stories. The 33 stories are grouped by region — Europe 8, Asia 8,
Africa 5, Middle East 3, Americas 3, Oceania 3, Global 3 — each with its
own region colour, a small vector scene, and the source named beside it.
All artwork is original flat vector drawing; no photos, no logos.
